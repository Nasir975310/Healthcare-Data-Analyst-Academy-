# Client handover checklist

- [ ] Confirm source owner, extraction date and refresh frequency.
- [ ] Confirm table grain, keys, units, code lists and status definitions.
- [ ] Review all exceptions with the source-system owner.
- [ ] Reconcile row counts and key totals before publication.
- [ ] Validate filters, date boundaries, totals and export behavior.
- [ ] Test role-level access using representative test identities.
- [ ] Remove direct identifiers from portfolio/public exports.
- [ ] Document refresh failure handling and escalation contact.
- [ ] Deliver data dictionary, KPI dictionary, model diagram and known limitations.
- [ ] Obtain client acceptance before operational use.
