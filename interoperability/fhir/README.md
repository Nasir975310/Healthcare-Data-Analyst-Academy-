# FHIR R4-style training examples

Files include simplified Patient, Encounter, MedicationRequest and Observation resources and a searchset Bundle with a synthetic `next` link.

The examples demonstrate resource identity, business identifiers, references, CodeableConcept/Coding, Quantity and Bundle pagination. They are training fixtures, not validated FHIR conformance resources. A production implementation must pin FHIR release and implementation guide, validate profiles and terminology bindings, use approved authentication and follow server-provided paging links.
