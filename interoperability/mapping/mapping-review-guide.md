# Terminology crosswalk review guide

Required columns: source system, source code, source display, target system, target code, target display, mapping relationship, mapping confidence, mapping status, terminology version, reviewer, review date, rationale and source reference.

## Mapping relationship
- Equivalent: concepts have the same intended meaning in the stated context.
- Wider: target is broader than source.
- Narrower: target is narrower than source.
- Related: concepts are associated but not equivalent.
- Unmapped: no safe target has been identified.

## Review rules
1. Do not map by label similarity alone.
2. Confirm context, specimen, method, property, timing and units for observations.
3. Confirm ingredient, strength, dose form, route and brand status for medications.
4. Preserve original source code and display.
5. Retain unmapped or ambiguous records in a review queue.
6. Record terminology edition/version and reviewer.
7. Re-review mappings when source or target releases change.
