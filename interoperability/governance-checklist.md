# Interoperability governance and security checklist

- [ ] Approved purpose, legal basis/authority and data-sharing agreement documented.
- [ ] Data minimisation and permitted use defined.
- [ ] PHI/PII inventory and data classification completed.
- [ ] Role-based access and least privilege applied.
- [ ] Authentication uses approved identity provider or service credentials.
- [ ] Secrets stored in a secrets manager/environment, never source code.
- [ ] Transport encryption and approved network boundary configured.
- [ ] Audit logs capture access, extraction, changes and administrative actions.
- [ ] Logs avoid unnecessary PHI and secrets.
- [ ] Retention, archival, deletion and backup policies approved.
- [ ] Patient identity matching uses governed identifiers and exception handling.
- [ ] Terminology versions and mapping decisions are traceable.
- [ ] Interface errors, retries, replay and dead-letter queues are monitored.
- [ ] Incident response and breach escalation are defined.
- [ ] De-identification or synthetic data is used for training and portfolio work.
