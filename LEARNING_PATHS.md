# Learning paths

These curated routes navigate the larger course-pack. Completion is defined by evidence, not time spent reading.

## Route A — Beginner to Healthcare Data Analyst

| Phase | Focus | Required output |
|---|---|---|
| A1 | Spreadsheet foundations: filters, formulas, pivots, lookup and charts | Clean workbook, data dictionary and reconciliation checks |
| A2 | SQL: SELECT, WHERE, GROUP BY, JOIN, CASE, CTEs and windows | Query file answering at least 10 analytical questions |
| A3 | Python: functions, files, pandas, NumPy and plotting | Reproducible notebook to import, profile and validate data |
| A4 | Statistics and healthcare measures | Methods note defining population, denominator and limitations |
| A5 | Flagship capstone | SQL/Python analysis, tests, report and case study |
| A6 | Career execution | Role-targeted CV, portfolio links and evidence-backed applications |

## Route B — SQL and BI focused

| Phase | Focus | Required output |
|---|---|---|
| B1 | Relational modelling, keys, grain and data quality | ER diagram and source-to-target mapping |
| B2 | Analytical SQL and performance basics | Tested query pack with metric definitions |
| B3 | Dashboard design and visual encoding | Dashboard wireframe and metric contract |
| B4 | Reconciliation, UAT and accessibility | UAT checklist, defect log and limitations (self-review labelled) |
| B5 | Portfolio delivery | Case study with actual project screenshots and reproducibility notes |

## Route C — Python and data engineering focused

| Phase | Focus | Required output |
|---|---|---|
| C1 | Python, pandas, testing and project structure | Small package with tests and deterministic outputs |
| C2 | SQL database integration | Re-runnable extraction and loading scripts |
| C3 | ETL, validation, logging and idempotency | Pipeline with data-quality checks and run manifest |
| C4 | Statistics and reporting | Quarto/Jupyter report with methods and caveats |
| C5 | Portfolio delivery | Clean-clone instructions, requirements and CI evidence |

## Flagship project
Prioritise the synthetic outpatient operations analytics capstone already included in the academy. Document source data, metric definitions, SQL, Python, tests, outputs, limitations and intended audience. Keep the synthetic antihypertensive utilisation exercise separate from the real Pharm.D thesis dataset.

## Definition of done
A phase is complete only when its output exists, can be reopened, has a short explanation and passes its stated checks. Link evidence in `PROGRESS_TRACKER.md`.
