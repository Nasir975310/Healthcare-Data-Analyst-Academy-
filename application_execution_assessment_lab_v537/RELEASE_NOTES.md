# v5.37.0 — Application Execution & Technical Assessment Lab

## Added
- Vacancy-to-evidence role-fit utility with explicit non-ATS caveat.
- Application tracker template and status-based descriptive metrics script.
- Five-minute portfolio walkthrough and reviewer scorecard.
- Executable SQL assessment against a generated synthetic SQLite fixture.
- SQL/Python practical brief, fixture CSV and reproducible setup.
- Ten-task interactive application execution roadmap.

## QA and limits
Tests cover fixture row counts, duplicate detection, role-fit bounds, application metrics and privacy labels. Role-fit is keyword-based and cannot determine true eligibility or hiring probability. Funnel metrics summarize each row's current status, not event-based conversion. No actual vacancy was assessed, no applications were submitted and no external hiring platform was accessed.
