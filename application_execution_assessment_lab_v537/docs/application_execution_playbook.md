# Application execution playbook

## 1. Select a role by evidence fit
Prioritize roles where the required tasks overlap with demonstrated work. A reasonable first target set:
- Junior Healthcare Data Analyst / Healthcare Reporting Analyst
- Clinical Data Analyst Intern / Research Data Assistant
- Pharmacy Operations Analyst / Medication-use data assistant
- Pharmacovigilance Data Associate (case processing and data quality focus)
- Junior SQL / Excel reporting analyst in a healthcare organization

Do not apply to roles requiring independent clinical decisions, production cloud ownership, senior experience or specialist tools you cannot demonstrate unless the employer explicitly offers training.

## 2. Read the job description
Extract: core deliverables, mandatory skills, preferred skills, domain knowledge, experience threshold, location/remote constraints, shift/time-zone, employment type, and application instructions. Separate mandatory from preferred. A keyword appearing in a job post is not proof you possess it.

## 3. Evidence-first tailoring
For every required skill, classify:
- Demonstrated: artifact + reproducible test.
- Practised: exercises or coursework, but no substantial project evidence.
- Learning: currently studying; do not present as proficiency.
- Not held: omit or state willingness to learn only when relevant.

Rewrite bullets as action + method + scope + verified result + limitation. Do not invent business impact, production experience, patient outcomes or client delivery.

## 4. Application quality gate
Before submitting:
- Role title and employer are correct.
- CV uses accurate education/employment dates.
- Every tool and metric claim is evidenced.
- Project is clearly labelled synthetic/academic where applicable.
- Resume and portfolio links open and do not expose secrets.
- Remote eligibility, location, hours, salary range and contract type are understood.
- No fee, OTP, password or payment is requested by a supposed recruiter.

## 5. Follow-up
Follow the employer's stated process. If no timeline is given, one concise follow-up after approximately 5–7 business days is reasonable; do not repeatedly message recruiters.

## 6. Weekly review
Track applications submitted, tailored applications, responses, screens, assessments, interviews, offers and withdrawals. Compare rates only when denominators are meaningful. A small sample is volatile; do not overinterpret a single week.
