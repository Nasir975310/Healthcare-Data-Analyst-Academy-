# Linux and Windows execution

## Linux (Fish, Bash or Zsh)
```bash
python -m pip install pandas
python project_simulator_v51/scripts/run_engagement.py
```

## Windows PowerShell
```powershell
py -m pip install pandas
py project_simulator_v51/scripts/run_engagement.py
```

Open the output folder in Thunar (Linux) or File Explorer (Windows). Import `encounters_accepted.csv` into DBeaver/DB Browser for SQLite and run the SQL script. Use VS Code to inspect the Python, CSV, SQL and Markdown files. The HTML Academy is a learning interface and does not execute these external scripts.
