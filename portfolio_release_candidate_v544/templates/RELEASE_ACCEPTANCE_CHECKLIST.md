# Portfolio release acceptance checklist

- [ ] Candidate archive built with status `LOCAL_CANDIDATE_READY`.
- [ ] Archive SHA-256 recorded and ZIP integrity checked.
- [ ] Candidate extracted into a fresh directory.
- [ ] Fresh-directory tests and pipeline pass.
- [ ] Repository preflight reports zero findings.
- [ ] Manual file-by-file privacy and provenance review completed.
- [ ] License selected only after confirming licensing rights.
- [ ] Dedicated GitHub repository created; correct visibility confirmed.
- [ ] Remote CI workflow completed successfully on the published commit.
- [ ] Clean remote clone reproduces tests and pipeline.
- [ ] External evidence recorded in the v5.43 handoff JSON and assessed.
- [ ] Independent reviewer has acknowledged scope and limitations.

Do not mark external items complete based on local fixture tests.
