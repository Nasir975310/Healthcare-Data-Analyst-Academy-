# Synthetic Healthcare Analytics Practicum

## Problem
A fictional teaching hospital needs an auditable view of encounter operations and medication-order patterns.

## Data and methods
Describe synthetic data, grain, ingestion, transformations, exclusions and SQL/Python tools.

## Findings
Report only reproducible descriptive results. Include denominators, periods and definitions.

## Quality controls
Explain uniqueness, referential integrity, missingness, range checks and raw-to-curated reconciliation.

## Dashboard
Add screenshots only after validating every visual against independent SQL outputs.

## Limitations
Synthetic data; not clinical evidence; medication orders do not establish dispensing or adherence; BP summaries are descriptive and not diagnosis/control rates.

## Reproduction
Provide exact environment, commands and expected outputs.

## Integrity statement
This is a self-directed educational portfolio project, not paid client work or employment experience.
