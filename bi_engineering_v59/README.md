# v5.9.0 — Healthcare Analytics BI Engineering & Semantic Modelling

This module provides synthetic encounter data, a SQLite semantic-view validation, Power BI model design, DAX measures, Power Query M, RLS guidance, dashboard blueprints and governance controls.

Start with `docs/semantic_model.md`, then run `python scripts/run_semantic_validation.py`. Import `data/encounters.csv` into Power BI Desktop on Windows and follow the model instructions.

**Execution boundary:** SQLite/Python validation is executable here. DAX and M are source examples for Power BI Desktop and are not executed by the Academy HTML interface or this validation script. No `.pbix` is generated. Data is synthetic.
