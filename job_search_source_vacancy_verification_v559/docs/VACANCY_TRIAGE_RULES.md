# Vacancy triage rules

- **New:** captured but not reviewed.
- **Reviewing:** eligibility and employer checks are in progress.
- **Verified:** all five checklist fields marked yes after independent checks; still subject to final human judgement.
- **Not verified:** one or more checks failed or legitimacy remains doubtful.
- **Expired:** deadline passed; confirm whether the employer still accepts applications before proceeding.
- **Applied:** application submitted through a channel you independently verified.
- **Closed:** no longer being pursued.

Do not use the status label `verified` merely because the script says a row is eligible for human final review. The script reports the evidence you entered; the user owns the decision and must retain the evidence.
