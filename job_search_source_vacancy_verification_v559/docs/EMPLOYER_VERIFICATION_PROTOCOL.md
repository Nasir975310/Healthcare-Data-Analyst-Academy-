# Employer and vacancy verification protocol

This protocol records checks a person has actually performed. Do not mark a check yes based on the vacancy's own claims.

1. Find the employer website independently using a trusted search engine or known corporate information.
2. Navigate to its careers page from that official site; check whether the same role, location and requisition details exist.
3. Inspect the sender/recruiter email domain for exact spelling and alignment with the employer. Independently contact the employer if uncertain.
4. Confirm job location, work authorisation, remote geography, shift, salary structure, employment type and deadline.
5. Reject requests for OTPs, passwords, banking credentials or payment to obtain employment, interviews, equipment or guaranteed placement.
6. Share only necessary personal information through a verified application portal at the appropriate hiring stage.
7. Record date, evidence source and unresolved uncertainty in verification_notes.

A legitimate company name can be impersonated. A HTTPS padlock only encrypts a connection; it does not establish that a site or recruiter is legitimate. If any key detail cannot be independently confirmed, leave it unknown and do not treat the vacancy as verified.
