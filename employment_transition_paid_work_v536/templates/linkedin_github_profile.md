# LinkedIn + GitHub launch checklist

## LinkedIn
- Headline: `Pharm.D | Healthcare Analytics | SQL • Python • Excel/Power BI [only verified skills]`
- About: explain clinical-domain foundation, the specific synthetic portfolio project, tools personally executed and target junior roles.
- Featured: one concise case study, repository, and a PDF/HTML report with synthetic-data label.
- Experience: use actual education, internships, rotations and employment dates. Do not list self-study as a job.
- Skills: prioritize demonstrable SQL, Excel, Python/pandas, data quality, healthcare analytics and communication.
- Open-to-work: choose realistic titles (Junior Healthcare Data Analyst, Clinical Data Analyst Intern, Pharmacy Data Analyst, Pharmacovigilance Data Associate).

## GitHub repository
- Clear problem statement, dataset provenance and synthetic-data warning.
- Reproducible setup with exact commands and dependency versions.
- Data dictionary, metric definitions, SQL/Python source, tests and sample outputs.
- No patient identifiers, secrets, `.env`, database files, private URLs or licensed data without permission.
- Include limitations, known issues and a truthful execution-status table.
- Add license only when you have the right to license all included material.

## Before sharing
Run the repository audit, inspect the rendered README, open every link, clone into a clean directory and reproduce the documented workflow. A repository existing is not evidence that it runs.
