# Release v5.36.0

## Purpose
Turn the Academy's existing technical practicum and employer evaluation into a practical job-search and first-paid-assignment workflow.

## New assets
- Evidence-to-claim map and truthful resume template.
- LinkedIn/GitHub profile publication checklist.
- 120-minute healthcare operations take-home brief.
- Technical interview simulator with structured scoring.
- Python JSON checklist scorer, example submission and five unit tests.
- Freelance statement of work and first-assignment risk guide.
- Interactive 12-task roadmap.

## QA boundaries
The scorer tests checklist presence and simple text patterns; it does not execute submitted SQL/Python, validate clinical correctness, or predict hiring outcomes. INR examples are arithmetic illustrations, not market-rate research. No external job applications, client contact, GitHub publication, Power BI execution or PostgreSQL deployment were performed as part of this release.
