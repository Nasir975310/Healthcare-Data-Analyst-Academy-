# Module compatibility and verification matrix

**Policy:** course-pack model. Modules retain their own dependency and execution instructions. This repository does not claim one supported Python version or complete compatibility. Check each module README before execution.

The packaged v5.60.3 archive includes the detailed module matrix and test-directory inventory. The historical test audit discovered 69 directories and remains incomplete; see [FULL_TEST_AUDIT_PROGRESS_v5.60.3.md](FULL_TEST_AUDIT_PROGRESS_v5.60.3.md).

Common external dependencies may include SQLite, PostgreSQL, R, Quarto, Docker, Chromium/Playwright and Power BI. Install only what the chosen module requires. Do not assume all modules can run in one Python environment.
