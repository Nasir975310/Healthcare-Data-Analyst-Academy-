# Release 5.25.0

## Healthcare Data Engineering & Clinical Data Interoperability
- FHIR Bundle ingestion for Patient, Encounter, Observation and MedicationRequest.
- Profile-limited structural validation and reference reconciliation.
- Separate resource-level data models and illustrative terminology mapping configuration.
- Data-quality report, patient-encounter longitudinal analytical table and transparent cohort flow.
- CSV, SQLite, JSON data dictionary and SHA-256 evidence manifest.
- Synthetic hospital analytics mini-project and nine automated tests.

## Important limitations
Not full FHIR R4 conformance; no official terminology server or authoritative ICD-10/SNOMED CT/LOINC mappings; synthetic records only; no production security or clinical decision support.
