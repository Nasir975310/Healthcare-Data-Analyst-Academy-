# Synthetic Hospital KPI Example

## Project overview
A training project summarising synthetic hospital encounters for an educational portfolio.

## Data and provenance
All records are synthetic. One row represents one encounter. No patient data are used.

## Methods
Python and SQL calculate encounter counts and mean length of stay.

## Reproducibility
Python 3.11+. Install with `pip install -r requirements.txt`. Run `python analyse.py`.

## Results
Outputs are descriptive summaries with explicit denominators.

## Quality assurance
Primary key uniqueness, null checks, range checks and row-count reconciliation are performed.

## Limitations
The data are simulated and do not represent a real hospital or support clinical inference.
