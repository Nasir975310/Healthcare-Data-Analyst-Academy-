# Reusable variable dictionary governance

The included dictionary is a starter library, not a universal clinical terminology. Copy and version a variable definition for each protocol. Reuse a name only when its operational definition, unit, measurement method, time point and permissible values match. Keep source terminology and local code mappings alongside canonical names. Never infer equivalence from similar labels alone.

A mature dictionary should add: source system, terminology code/version, collection instrument, derivation, missing-value semantics, sensitivity classification, owner, effective dates and approval history.
