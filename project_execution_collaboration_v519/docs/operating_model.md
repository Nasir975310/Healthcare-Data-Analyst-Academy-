# Project operating model

1. **Initiate:** create a workspace and complete the project plan.
2. **Govern:** confirm data authorization, classification, cohort definitions, and access restrictions.
3. **Execute:** develop analysis in version-controlled Python, SQL, or R source files; add tests for transformations and metrics.
4. **Review:** record reviewer feedback and resolve revision requests.
5. **Control change:** register scope/method changes with impact and decision status before implementation.
6. **Baseline:** create a release snapshot and retain its hashes with the project version.
7. **Accept:** complete handover documentation and human acceptance checks.

The workspace is a project coordination aid, not a multi-user server or formal electronic records system.
