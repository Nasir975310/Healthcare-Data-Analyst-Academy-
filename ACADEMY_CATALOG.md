# Academy Catalog and Navigation

The academy is cumulative. Use `index.html` for the offline learning interface, `projects/` for curated capstone entry points, and each versioned module README for exact commands and prerequisites.

## Main learning and practice areas
- Excel and spreadsheet analysis
- Descriptive/inferential statistics, epidemiology and clinical research methods
- SQL, SQLite, PostgreSQL and healthcare data modelling
- Python foundations, pandas analysis and reproducible workflows
- Data quality, ETL, data engineering and interoperability
- Visualisation, reporting, Power BI modelling and dashboard QA
- Clinical pharmacy and medication-utilisation analytics
- Portfolio engineering, evidence capture and publication-readiness checks
- Job simulations, career materials, vacancy triage and interview preparation

## Major capstone families in the packaged academy
The cumulative distribution contains foundational Excel/SQL, Python, integrated healthcare portfolio, biostatistics/research, clinical pharmacy analytics, BI/data engineering, predictive analytics and career toolkit materials. Detailed module paths and file inventories are retained in the original package's module directories.

## Career workflow
Follow v5.55 → v5.56 → v5.57 → v5.58 → v5.59 → v5.60. The sequence moves from career materials to job-fit evaluation, interview preparation, application metrics, vacancy verification and evidence-backed shortlisting.

## Evidence vocabulary
- **Included:** file or instruction exists in the package.
- **Locally tested:** automated test or local smoke check passed in the build environment.
- **User-side pending:** requires execution on the user's machine or account.
- **External verification pending:** requires an independent employer, recruiter, reviewer, repository or hosted service.

A module being included or locally tested is not proof of external acceptance or employment readiness.
