# Healthcare Analytics Dashboard Studio — v5.3.0

A browser-local dashboard builder with CSV loading, date and department filters, KPI cards, bar/line/donut/table views, layout selection, metric definitions, dashboard QA checklist and standalone HTML export.

The included dataset is synthetic. Browser analysis is local to the tab. This is a training tool, not validated BI software. It does not execute SQL, DAX, Power Query or infer clinical quality.
