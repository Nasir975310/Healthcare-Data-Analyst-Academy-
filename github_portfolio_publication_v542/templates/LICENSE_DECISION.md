# License decision worksheet

No license is included automatically.

Before selecting a license, confirm:
1. You own or have permission to license every code, text, image and dataset component.
2. Dataset terms allow redistribution.
3. Third-party dependencies and copied materials retain their required notices.
4. You understand the consequences of the license.

Common choices to research:
- MIT: permissive software license.
- Apache-2.0: permissive license with express patent provisions.
- GPL-3.0: copyleft software license.
- CC BY 4.0: commonly used for creative/textual content, not generally preferred for software code.

This worksheet is not legal advice. If ownership or redistribution rights are unclear, do not add a license or publish the material until resolved.
