# PRAC-03 — Remote client request-to-handoff: starter pack

**Client:** Healthcare analytics vendor project manager  
**Timebox:** 3 working days

Client asks whether support is getting faster and which team is underperforming. No team field is supplied; do not invent a team comparison. Clarify first-response vs resolution time, business-hours calendar, timezone and open-ticket treatment. Dataset only supports elapsed clock-hours from opened_at to closed_at for closed tickets. Report open/missing closure separately. Stratify by priority and client type with counts; do not rank small groups as poor performers.
