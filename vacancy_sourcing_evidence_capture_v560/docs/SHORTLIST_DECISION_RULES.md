# Shortlist decision rules

- **Shortlisted:** role appears potentially suitable after first-pass review; still requires employer verification.
- **New:** captured but not evaluated.
- **Not suitable:** mandatory eligibility criteria clearly fail.
- **Verification pending:** employer, recruiter, source or vacancy status requires independent checks.
- **Verified by user:** the user has completed the v5.59 verification process and retained supporting evidence; not a platform guarantee.
- **Applied:** submitted through an independently checked channel.
- **Expired:** deadline has passed; confirm whether applications remain open.
- **Closed:** no longer being pursued.

A high priority score cannot override a mandatory eligibility failure, suspicious payment request, unverifiable recruiter, or unsafe data request.
