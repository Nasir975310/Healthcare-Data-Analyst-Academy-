# Excel and Power Query lab quick start

1. Open `starter/healthcare_excel_powerquery_lab.xlsx`.
2. Read `START_HERE`, then inspect `Raw_Encounters`, `Raw_Orders` and `Formulary`.
3. Work through `Tasks` and the Academy's **Excel mastery** view.
4. Use `Reference_Checks` only after attempting the calculations.
5. Use `powerquery/clean_orders.m` for the Windows Excel Power Query route.
6. On Linux, run `python scripts/excel_lab_cleaning.py` from the Academy root, or use LibreOffice Calc for formulas and PivotTables.
7. Complete EX08 under a 45-minute time limit and self-score against the rubric.

Do not replace the synthetic data with patient-identifiable data.
