# v5.0 Professional simulation protocol

## Candidate instructions
- Use synthetic data only. Never upload patient-identifiable data.
- Complete the four written scenarios under the suggested time limits.
- Run the SQL and Python tasks locally; the browser cannot execute either language.
- Record actual evidence paths and scores. Self-scored written answers are not independently verified.
- Treat model answers as review material after attempting each task.

## Scoring
The four written scenarios total 65 points. Each rubric item is worth an equal share of that scenario's points. Self-assess each item as 0 (not demonstrated), 0.5 (partially demonstrated), or 1 (clearly demonstrated). SQL/Python local practical evidence and interview performance are separately recorded and are not included in the auto-calculated written score.

## Suggested readiness interpretation
- 85–100%: strong evidence in this assessment; validate with a second independent project.
- 70–84%: developing; close the specific rubric gaps.
- 50–69%: foundational gaps remain.
- Below 50%: revisit the relevant curriculum and repeat with a fresh case.

This is a formative learning tool, not a validated examination, hiring decision, professional certification or clinical quality assessment.
