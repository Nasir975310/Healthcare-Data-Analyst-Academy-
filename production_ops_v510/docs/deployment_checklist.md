# Deployment readiness checklist

- [ ] Named business owner, technical owner and data steward.
- [ ] Approved source, lawful purpose, data minimisation and retention.
- [ ] Data classification and threat model completed.
- [ ] Access control, encryption in transit/at rest and backup access tested.
- [ ] Schema contract and change process versioned.
- [ ] Duplicate, null, range, referential and freshness rules approved.
- [ ] Quarantine workflow has owner, SLA and safe reprocessing procedure.
- [ ] Source-to-target reconciliation signed off.
- [ ] Monitoring, alerting, incident response and escalation tested.
- [ ] Recovery and rollback rehearsed.
- [ ] Dashboard RLS and export controls tested with real role identities.
- [ ] Change log, runbook, lineage and support ownership published.
- [ ] Clinical metric definitions reviewed by qualified domain owner.

A checked list is an operational record only when the named owners provide evidence; this template does not certify compliance.
