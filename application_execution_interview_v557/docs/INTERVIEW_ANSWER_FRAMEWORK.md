# Evidence-led answer framework

Use **Context → Task → Method → Validation → Result → Limitation → Learning**.

- Identify whether the example is academic, thesis-based, synthetic or professional.
- Define the analytical question and unit of analysis.
- Explain only methods actually used.
- Describe row counts, missingness, duplicates, range checks, reconciliation and reproducibility where relevant.
- Report only results reproducible from source files.
- State limitations such as confounding, selection, missing data, sample size and generalisability.
- Never present a synthetic exercise as hospital work or academic work as paid employment.
