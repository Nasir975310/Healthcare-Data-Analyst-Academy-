# Status methodology

- **Completed:** a corresponding capability is present in the cumulative Academy release or has an executed local QA result.
- **Partial:** useful supporting material or isolated implementation exists, but the complete user requirement is not demonstrated.
- **Pending:** no complete implementation has been verified.
- **Needs verification:** reserved for capabilities whose implementation exists but whose target environment or correctness needs separate evidence.

This roadmap deliberately does not treat educational content as a live integration. For example, GitHub learning material is not GitHub OAuth; DAX examples are not a tested PBIX; AI-readiness proposals are not connected AI providers; local HTML is not proof of full Android and browser compatibility.
