# v5.39.0 — Portfolio Presentation & Employer Review

## Purpose
This is a completion gate for the synthetic outpatient operations analytics project added in v5.38. It does not add another course. It helps you inspect whether the project is technically defensible, documented, reproducible and presentable to an employer.

## Start here
1. Read `docs/REVIEW_PROTOCOL.md`.
2. Run the technical evidence audit:
   ```bash
   python src/review_evidence.py --project ../portfolio_execution_reproducibility_v538 --evidence evidence
   ```
3. Complete `templates/CASE_STUDY.md` using outputs generated by the v5.38 pipeline.
4. Reproduce the project from a clean copy and record the commands/results in `evidence/reproduction_log.md`.
5. Rehearse `docs/FIVE_MINUTE_WALKTHROUGH.md`.
6. Complete `templates/EMPLOYER_REVIEW_SCORECARD.md`.

## What the audit does
The audit checks for a defined set of expected project artifacts and user-supplied evidence files. It produces a JSON report and a Markdown summary. It does **not** execute or certify the upstream project, verify a GitHub remote, inspect a live Power BI report, or prove that the author can explain the work.

## Readiness gates
- **Technical artifact gate:** expected source, tests, SQL and documentation exist.
- **Reproduction gate:** user records a clean-run log and the reviewer can repeat it.
- **Communication gate:** case study and walkthrough are complete and consistent with outputs.
- **Publication gate:** repository is public or intentionally shared, contains no sensitive data/secrets, and has a useful README.
- **Interview gate:** user can explain grain, metric definitions, exclusions, limitations and design trade-offs without reading a script.

Do not mark a gate passed solely because the automated scanner reports no missing files.

## Scope and honesty
The dataset is synthetic. This project is an educational portfolio artifact, not clinical decision support, a validated hospital performance study, or evidence of paid professional experience. No GitHub publication, employer review, Power BI execution or client engagement is claimed by this release.
