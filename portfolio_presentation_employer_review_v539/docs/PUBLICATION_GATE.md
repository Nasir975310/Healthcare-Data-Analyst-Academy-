# Publication gate

Mark each item only after inspecting the corresponding evidence.

- [ ] All data are synthetic, licensed, or explicitly authorized; no PHI/PII.
- [ ] Repository secret scan and manual review completed.
- [ ] README has prerequisites, setup, run, tests, expected outputs and limitations.
- [ ] Clean-clone reproduction completed on a separate directory or machine.
- [ ] Tests pass from documented commands.
- [ ] Case-study values reconcile to generated output files.
- [ ] No unsupported clinical, causal, or business-impact claims.
- [ ] License and data provenance are clear.
- [ ] Screenshots are genuine, current and captioned.
- [ ] GitHub visibility/access decision is intentional.
- [ ] Reviewer feedback and unresolved issues are documented.

**Release decision:** HOLD until every applicable item is checked. A local preflight scanner is not a substitute for manual review.
