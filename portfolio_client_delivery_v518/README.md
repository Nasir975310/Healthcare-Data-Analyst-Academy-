# v5.18.0 — Healthcare Analytics Portfolio & Client Delivery Platform

A local-first project packaging tool for healthcare analytics work. It creates an auditable project manifest, input hash, structural data dictionary, environment manifest, executive and technical report templates, portfolio case study, acceptance checklist, and handover ZIP.

Run `python scripts/delivery_builder.py --help` for options. Sample input is synthetic. Automated sensitive-column-name scanning is a warning only and is not a de-identification or privacy certification.
