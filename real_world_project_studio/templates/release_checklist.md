# Project release checklist

- [ ] Data is synthetic, public, or explicitly authorised for this use
- [ ] No PHI, secrets, tokens, or confidential employer data
- [ ] Grain, keys, joins and duplicate policy documented
- [ ] Metric contracts approved by intended stakeholder
- [ ] Source-to-output lineage documented
- [ ] Data-quality exceptions quantified and dispositioned
- [ ] Code runs from a clean environment using documented commands
- [ ] Tests cover critical assumptions and failure cases
- [ ] Outputs reconcile to source totals
- [ ] Clinical/operational interpretation is within design limits
- [ ] Screenshots are current and do not expose sensitive information
- [ ] Reviewer sign-off and version/date recorded
