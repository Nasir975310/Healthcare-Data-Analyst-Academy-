# Clinical analytics reporting checklist

## Before analysis
- [ ] Research question and estimand written before outcome analysis.
- [ ] Target population, eligibility, index date, exposure and outcome defined.
- [ ] Primary outcome, time horizon and primary comparison specified.
- [ ] Confounders selected using subject-matter knowledge, not automated p-value screening.
- [ ] Data provenance, dictionary, units, missingness and quality checks documented.
- [ ] Analysis plan records planned vs exploratory analyses.

## During analysis
- [ ] Cohort flow and exclusions reconciled.
- [ ] Denominators and unit of analysis stated for every table.
- [ ] Missing-data approach justified.
- [ ] Model assumptions and diagnostics reviewed.
- [ ] Effect estimates and confidence intervals reported with p-values where appropriate.
- [ ] Sensitivity analyses address plausible alternate assumptions.
- [ ] No leakage from future or outcome-derived variables.

## Reporting
- [ ] Descriptive table with group-specific denominators.
- [ ] Primary effect estimate, confidence interval, units and interpretation.
- [ ] Statistical significance distinguished from clinical importance.
- [ ] Limitations include bias, confounding, measurement error and generalisability.
- [ ] Code, software versions, data dictionary and synthetic data provenance retained.
- [ ] STROBE checklist considered for observational reports; CONSORT for randomised trials.
- [ ] No PHI or credentials in portfolio files.

STROBE and CONSORT are reporting guidelines, not substitutes for sound design or critical appraisal.
