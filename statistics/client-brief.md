# Client brief: Clinical outcomes analysis

**Time allowed:** 120 minutes. **Audience:** Clinical research and pharmacy service leads.

Using only the synthetic cohort file, prepare a reproducible report addressing:
1. Cohort characteristics and data-quality profile.
2. Unadjusted difference in follow-up SBP between simulated groups with a 95% CI.
3. Adjusted linear regression with coefficient interpretation and diagnostics.
4. A separate logistic model demonstration with holdout discrimination and calibration caveats.
5. Time-to-event analysis plan that identifies event definition, censoring and proportional-hazards assumption.
6. A concise executive summary distinguishing association from causation.

Deliverables: analysis plan, Python/R code, tables, one figure, reproducibility manifest, limitations and a 5-minute handoff.

Critical: The cohort is artificial. The event is simulated. The output must not be represented as clinical evidence, a validated prediction model or treatment-effect evidence.
