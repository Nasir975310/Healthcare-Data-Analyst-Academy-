# Release v5.56.0 — Application Intelligence & Job Search Execution

Adds `application_intelligence_v556/`, a standard-library CLI that accepts a job-description text file and optional profile JSON, then emits JSON and Markdown assessment reports. Scoring covers skills/tools, education, experience, remote alignment, healthcare domain and transferable baseline. It flags selected textual risk patterns and gives a human verification checklist.

The tool is deterministic and transparent; it is not an AI model, ATS replica or probability-of-hire estimator. Example vacancy is fictional. No current vacancies were searched, no employer was verified, and no job application was submitted. User must edit profile to reflect only skills and evidence they can substantiate.
