# Volume 3 Python foundations practice project

1. Keep this project folder and the academy `datasets/v03_python` folder in the same academy root.
2. Open the academy root in VS Code.
3. Run the starter with `python projects/v03_python_foundations/starter/inspect_encounters.py`.
4. Complete the TODOs, then compare with `solutions/inspect_encounters_solution.py`.
5. For Chapter 5, install NumPy in a virtual environment and run the array exercises.

The first four chapters use the Python standard library. NumPy is introduced in Chapter 5. Do not install packages globally merely to complete this course.
