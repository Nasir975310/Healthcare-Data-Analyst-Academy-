# Final professional readiness scorecard

Score each domain from 0 to 3 using evidence, not confidence.

| Score | Meaning |
|---|---|
| 0 | Cannot yet perform; no evidence |
| 1 | Can explain concepts; needs substantial guidance |
| 2 | Can complete a bounded task with review |
| 3 | Can complete, validate, document and explain independently within scope |

## Competency domains
- Excel/spreadsheet analysis
- SQL querying, joins and reconciliation
- Python/pandas data preparation
- Statistics and interpretation
- Healthcare data concepts and terminology
- Data quality and governance
- BI/dashboard communication
- Git and reproducibility
- Linux execution and troubleshooting
- Windows PowerShell execution and troubleshooting
- Written communication and stakeholder clarification
- Privacy, security and professional ethics
- Portfolio presentation and interview readiness

## Evidence rule
For every score of 2 or 3, attach a project, test result, reviewed deliverable or practical demonstration. Do not award a 3 solely for watching lessons or completing a quiz.

## Suggested decision
- Any 0 in privacy, data quality or core SQL/Python: prioritise remediation before claiming job readiness.
- Mostly 1s: continue guided practice and complete portfolio projects.
- Mostly 2s: apply to appropriately scoped junior roles while improving.
- Consistent 3s with reviewed evidence: pursue roles requiring independent ownership within the demonstrated scope.

This scorecard is a self-assessment aid, not an accredited qualification or guarantee of employment.
