# V08 Career Launch Toolkit

Templates are intentionally blank. Keep job-search records private; do not commit personal identity documents, passwords, recruiter private correspondence or client information to public repositories.

## Contents
- `job_application_tracker.csv` — private application pipeline.
- `skills_evidence_matrix.csv` — map job requirements to demonstrated evidence.
- `90_day_plan.csv` — onboarding and development plan.
- `portfolio_review_checklist.csv` — public-safe project quality review.
- `proposal_template.md` — bounded consulting proposal structure.
- `mock_interview_bank.md` — technical, clinical and behavioural practice.
- `final_readiness_scorecard.md` — evidence-based competency review.

## Linux and Windows
Open CSV/Markdown files in LibreOffice/OnlyOffice/Microsoft Excel or a text editor. Use your file manager, or terminal:
- Linux Bash/Zsh: `ls -la`; Fish supports `ls -la`.
- Windows PowerShell: `Get-ChildItem -Force`.
Do not store private job-search records in a public Git repository. If you version public portfolio templates, inspect staged files before committing.
