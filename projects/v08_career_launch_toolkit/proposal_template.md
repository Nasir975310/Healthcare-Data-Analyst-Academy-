# Small healthcare analytics project proposal template

## 1. Client problem
- What decision or operational question needs support?
- Who will use the deliverable?

## 2. Scope
- Dataset(s), record grain, size and format:
- Permitted data and approved processing environment:
- Analysis and transformations included:
- Deliverables and file formats:

## 3. Exclusions
State what is not included: clinical recommendations, regulatory submissions, production deployment, unlimited revisions, unsupported data sources, or work outside agreed competence.

## 4. Assumptions and dependencies
List data access, data dictionary, stakeholder availability, software, approvals and client responsibilities.

## 5. Timeline and milestones
| Milestone | Deliverable | Review/acceptance criteria | Target date |
|---|---|---|---|
| Discovery | Confirmed requirements | Written scope approval | |
| Build | Draft analysis | Agreed checks pass | |
| Review | Revised output | One agreed review cycle | |
| Handoff | Final files and README | Client confirms receipt | |

## 6. Fees and payment
State fixed fee or rate, estimate assumptions, payment milestones, currency, platform fees and late-payment terms. Verify applicable tax and legal obligations with a qualified adviser.

## 7. Privacy, security and ownership
Do not accept identifiable health data until lawful authority, client permissions, approved systems, access controls, retention, deletion and contractual terms are confirmed. Define ownership and permitted reuse of code and deliverables.

## 8. Change control
Describe how additional datasets, changed definitions, extra revisions or scope expansion will be estimated and approved.

## 9. Acceptance
Define the objective checks by which the client accepts each deliverable.
