# Flagship project: synthetic outpatient operations analytics

Demonstrate an end-to-end healthcare analytics workflow using synthetic training data: define operational questions, inspect data grain, validate data quality, define metrics, query with SQL, analyse with Python, reconcile outputs and communicate limitations.

The detailed project materials and tests are contained in the academy's existing course-pack modules. Use `ACADEMY_CATALOG.md` and search for outpatient, dashboard, capstone and metric contract to locate the project brief, datasets, SQL, Python and outputs. This entry point does not duplicate or silently alter source material.

## Minimum portfolio evidence
- Project brief and intended audience.
- Data dictionary, provenance and synthetic-data declaration.
- Explicit row grain, inclusion/exclusion rules and date window.
- Metric contract: definition, numerator, denominator, null handling and validation.
- SQL queries and Python analysis with reproducible setup.
- Tests and reconciliation checks.
- Dashboard/report captured from the actually executed project.
- Limitations, bias considerations and non-clinical-use statement.

Do not claim clinical deployment, patient-care impact, employer validation, public release or dashboard UAT without separate evidence. Never substitute synthetic outputs for real clinical findings.
