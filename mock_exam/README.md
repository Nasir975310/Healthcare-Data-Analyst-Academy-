# Capstone mock examination

- 75-minute suggested duration.
- 15 questions: 10 MCQ (5 points each), 2 SQL tasks (10 points each), 3 interpretation tasks (10 points each).
- Total: 100 points.
- The browser checks MCQs automatically; written responses require self-assessment against answer guidance.
- Suggested interpretation: 85–100 strong practice performance; 70–84 developing; 55–69 targeted remediation; below 55 revisit foundations. These are learning bands, not credential thresholds.
- The answer key is revealed after submission. Reset clears the local attempt.
- Not an accredited certification, licensure exam or employer endorsement.
