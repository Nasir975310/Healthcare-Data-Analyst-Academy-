# Application workflow

## 1. Triage the vacancy
Check the employer's official careers page and record:
- Exact title, requisition ID, location and work mode (remote/hybrid/onsite).
- Degree eligibility, graduation-year limits, experience, shift and travel requirements.
- Required technical tools and healthcare domain.
- Application deadline and official application route.
- Whether the job is direct employment, contract, internship or third-party staffing.

## 2. Score role fit
Score each dimension 0–2:
- Degree and eligibility fit.
- Experience-level fit.
- SQL / Excel / BI fit.
- Python / statistics fit.
- Healthcare-domain fit.
- Evidence/portfolio fit.
- Work-mode and shift fit.
- Communication and documentation fit.

Interpretation:
- 13–16: strong application priority.
- 9–12: apply if no hard eligibility mismatch; close the top gaps.
- 5–8: stretch application; invest only if the role is unusually valuable.
- 0–4: low priority.

Hard disqualifiers (e.g. degree/pass-out-year restriction, mandatory years of experience, work authorisation, location) override the numerical score.

## 3. Tailor evidence, not keywords
- Mirror relevant terminology only when you can substantiate it.
- Reorder skills and projects to match the role.
- Use measured outcomes and describe QA.
- Never claim production EDC, MedDRA, CDISC, Power BI, claims or EHR experience unless actually obtained.
- Do not claim Academy work as paid employment.

## 4. Submit and record
- Apply through the employer's official site where possible.
- Save the job description and submitted CV version.
- Record date, role, status, contact, follow-up date and next action.
- Follow up once after a reasonable interval; respect employer instructions.

## 5. Weekly review
- Review conversion by stage: applications, recruiter screens, technical tests, interviews, offers.
- If no screens after 20 well-matched applications, revise role targeting and CV evidence.
- If screens but no technical pass, practise the relevant assessment.
- If technical passes but no final offer, improve project explanation and behavioural examples.
- Do not spam generic applications.
