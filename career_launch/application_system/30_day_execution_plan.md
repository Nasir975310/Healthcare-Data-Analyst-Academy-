# 30-day career launch plan

Designed for a learner who wants to build evidence while beginning applications, not wait until every topic is mastered.

## Days 1–3: Positioning
- Choose two primary role families and one adjacent backup.
- Audit five live vacancies on official employer sites.
- Complete the role scorecard and identify hard eligibility gates.
- Draft a one-page CV and LinkedIn headline.

**Output:** role map, five scorecards, CV v1.

## Days 4–7: Portfolio proof
- Finish one hospital operations capstone to reproducible status.
- Add a concise executive summary, data dictionary, SQL/Python, QA log and limitations.
- Re-run the analysis from a clean environment.
- Remove any personal or confidential information.

**Output:** one complete portfolio repository.

## Days 8–10: Hiring practice
- Complete SQL and Python timed assessments.
- Practise explaining a join, denominator, orphan record and data-quality issue.
- Fix weak areas and retain a revised solution.

**Output:** two assessment artifacts and a gap list.

## Days 11–14: First applications
- Apply to 3–5 high-fit vacancies, including relevant trainee/associate roles.
- Tailor CV headline, skills and project order to each vacancy.
- Use the employer's official application channel.
- Record the exact CV version and next action.

**Output:** first 3–5 tracked applications.

## Days 15–21: Parallel learning and applications
- Complete clinical data or PV project relevant to the roles targeted.
- Apply to another 5–8 matched vacancies.
- Practise one mock interview and one client communication simulation.
- Request feedback from a credible mentor or peer if available.

**Output:** second portfolio artifact, 8–13 cumulative applications, interview notes.

## Days 22–30: Funnel review
- Review application-to-screen and screen-to-assessment conversion.
- If there are no screens after 10–20 well-matched applications, revise targeting and CV proof.
- If technical assessments are the bottleneck, practise the exact failed skill.
- If interviews are the bottleneck, improve concise project narratives and behavioural examples.
- Continue applying while improving; do not pause all applications for another course.

**Output:** 30-day review, updated CV, two portfolio artifacts, application funnel and next 30-day plan.

## Weekly operating rhythm
- 3 focused skill/portfolio sessions.
- 2 application sessions.
- 1 timed assessment or mock interview.
- 1 review and documentation session.

Adjust the workload around exams, clinical rotations and other commitments.
