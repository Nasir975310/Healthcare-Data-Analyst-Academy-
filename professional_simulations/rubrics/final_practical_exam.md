# Final Professional Practical Examination

**Time:** 4 hours · **Total:** 100 points · **Pass threshold:** 70 points, with no critical integrity failure.

## Brief
You receive the three synthetic simulation datasets and a client request to produce an integrated monthly healthcare analytics handoff. You must scope the request, profile and quarantine data, calculate defensible metrics, document denominators, write reproducible SQL/Python, and communicate limitations.

## Required deliverables
1. Scope and metric-definition sheet (10)
2. Data profiling, issue register and quarantine strategy (15)
3. SQL analysis with safe joins and denominator checks (15)
4. Python analysis with reproducible outputs (15)
5. Clinical/statistical interpretation and limitations (15)
6. Dashboard or executive KPI pack (10)
7. Client clarification and final handoff (10)
8. Reproduction instructions, test evidence and data disclosure (10)

## Critical integrity failures
Any PHI/credential disclosure, silent deletion of material data-quality issues, fabricated results, unsupported causal/clinical claims, or failure to disclose synthetic data blocks a pass regardless of score.

## Assessment protocol
- Work from the supplied raw files.
- Record start/end time and any assumptions.
- Do not inspect reference solutions until the first submission is complete.
- Self-score using the rubric, then compare with reference outputs.
- Re-run from a clean output directory and record differences.
- A passing self-score is not an accredited credential or independent employer assessment.
