# Self-score interpretation

- **90–100:** Strong submission; still requires independent review.
- **80–89:** Good foundation; address specific rubric gaps.
- **70–79:** Developing; repeat weak sections before using as portfolio evidence.
- **Below 70:** Rework scope, data quality, calculations or communication before submission.

A score cannot override critical integrity failures. Any PHI/credential exposure, fabricated result, unauthorised data use, unsupported clinical claim or concealed material data issue blocks portfolio release. Scores are self-assessment and not employer ratings.
