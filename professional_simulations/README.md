# Professional Simulation Environment — v3.7

All datasets are synthetic. No real patient or employer data are included.

## Included assignments
- SIM-04 Hospital Operations Incident Review (120 minutes)
- SIM-05 Antihypertensive DUE Analytical Review (150 minutes)
- SIM-06 Remote Client Data Quality Escalation (90 minutes)
- FINAL-01 Integrated Professional Practical Examination (240 minutes)

Each assignment has a scenario, inputs, deliverables, acceptance criteria and a point-based rubric. The interactive Academy view tracks deliverables, status, time, self-score and reflection in browser localStorage.

## Run reference solutions
From the Academy root:
```bash
python professional_simulations/solutions/run_sim04_hospital_review.py
python professional_simulations/solutions/run_sim05_due_review.py
```
Reference outputs are generated in `professional_simulations/outputs/`. SIM-06 includes SQLite query examples.

## Suggested assessment process
1. Download the brief and work from raw data.
2. Record assumptions and definitions before analysis.
3. Produce outputs and quality checks.
4. Complete the handoff and limitations.
5. Only then compare your results to reference outputs.
6. Re-run from a clean output directory and record reproducibility evidence.

These are formative simulations, not accredited examinations, validated clinical evidence or guarantees of employment.
