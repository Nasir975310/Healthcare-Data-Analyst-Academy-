# v4.7.0 — Healthcare Analytics Technical Production Environment

This pack gives you one consistent starter project for Linux/Ryoku and Windows. It contains a Python package scaffold, isolated-environment setup guides, tests, Ruff configuration, SQL exercises, SQLite loader, optional local PostgreSQL Docker Compose service and a 150-row synthetic encounter CSV.

## Important boundaries
- This is a local training scaffold, not a production clinical system.
- The included dataset is fictional and contains no real patient records.
- The PostgreSQL compose service is optional; SQLite requires no server.
- Setup checkboxes in the academy are self-reported. The browser does not inspect or configure your computer.
- Docker Compose uses a disposable example password and binds the port to localhost. Do not expose it or reuse the password.
