# Power BI mastery laboratory

This folder contains the Academy v2.3.0 BI learning assets:
- `MODEL_RELATIONSHIPS.md` — model relationships and filter directions.
- `DATA_MODEL.mmd` — Mermaid model diagram source.
- `measures.dax` — reusable starter DAX measures.
- `REPORT_BLUEPRINT.md` — three-page report specification.
- `PLATFORM_GUIDE.md` — Windows Power BI and Linux Streamlit routes.
- `import_fact_medication_orders.m` — Power Query M example.
- `hda_powerbi_theme.json` — importable Power BI theme.
- `model_reference_checks.json` — independently calculated controls.
- `CLIENT_HANDOFF_TEMPLATE.md` — professional delivery template.

No `.pbix` file is included because PBIX authoring requires Power BI Desktop. The M and DAX files are educational references and were not executed in Power BI Desktop during package QA.
