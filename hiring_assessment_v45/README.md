# v4.5 Hiring Assessment Centre

A self-administered, employer-style assessment sequence using synthetic cases. It simulates screening, technical tasks, healthcare interpretation, dashboard review, take-home delivery and a hiring-manager review. It is not a validated psychometric test, real employer assessment or certification.

Recommended use: complete the timed attempt without notes, save your work in a separate repository, then use the rubric for a second review. Record actual SQL/Python/Excel/BI outputs. The browser app stores responses locally and cannot execute or verify those tools.
