# Stage 6 — Take-home assignment (90 minutes)

Choose one synthetic engagement from `practicum_v43/`.

Submit:
- Business question and scope.
- Data dictionary and metric contract.
- Reproducible SQL/Python/Excel/BI artefact.
- Data-quality log and exception handling.
- Two or three findings with denominators.
- Limitations and privacy statement.
- README with environment, run instructions and expected outputs.
- Short client handoff.

Reviewer must be able to reproduce one key result from the raw synthetic source. A polished screenshot without source logic is insufficient.
