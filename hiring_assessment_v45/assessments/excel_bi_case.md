# Stage 4 — Excel and BI case (30 minutes)

A manager wants a monthly department dashboard.

Tasks:
1. Define encounter volume, mean/median LOS and a supplied outcome-flag rate.
2. State grain, numerator, denominator, period, exclusions and source for each KPI.
3. Design a summary table and two appropriate visuals.
4. Identify how you would test filter interactions and totals.
5. Explain how to prevent order-level joins from inflating encounter metrics.
6. Write a three-sentence executive interpretation with no unsupported causal claim.

**Linux note:** Use LibreOffice Calc or a Python/Streamlit/Plotly alternative for practice. These do not fully reproduce Excel Power Query or Power BI Desktop.
