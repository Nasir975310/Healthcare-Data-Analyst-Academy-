# Release 1.9.0 — Practical laboratory retrofit

## Added
- Eight guided labs covering Python environment setup, pandas profiling, SQL analytics, biostatistics, clinical pharmacy analytics, ETL/data marts, dashboard design and predictive-model evaluation.
- Searchable Practical Labs app view with expandable instructions.
- Per-lab deliverables, prerequisites, OS-specific commands, step-by-step workflow, acceptance criteria, troubleshooting, precautions and portfolio guidance.

## Important limitations
- Linux instructions target a Fish shell on an Arch-based workstation; Windows instructions target PowerShell 7.
- Windows commands were not executed on a Windows host during this release.
- Power BI Desktop is not natively supported on Linux; alternatives are not feature-equivalent.
- The browser app presents learning content and does not execute Python, SQL or R.
- Synthetic data only. No clinical deployment or patient-level decision use is supported.
