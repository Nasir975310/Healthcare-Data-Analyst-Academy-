# Release 2.0.0 — Job simulations and portfolio evidence

## Added
- Searchable Job Simulations app view.
- SIM-01: Excel hospital operations review.
- SIM-02: SQL prescribing and encounter analysis.
- SIM-03: remote client request-to-handoff simulation.
- Synthetic datasets: 80 encounter rows and 150 medication-order rows.
- Excel workbook with Read_Me, Encounters and Medication_Orders sheets.
- SQL starter and worked SQLite solution.
- Client clarification and analytical handoff templates.
- Rubrics, deliverables, acceptance criteria, pitfalls and portfolio guidance.

## Learning objectives
Assignments assess practical analysis and professional workflow: requirement clarification, table grain, denominator discipline, join cardinality, QA, interpretation, limitations and stakeholder communication.

## Limitations
- Data are synthetic, not real hospital records.
- Synthetic readmission flag is not a validated quality metric.
- Medication-order records do not establish dispensing, administration or adherence.
- Windows instructions are provided but were not executed on a Windows host.
- The browser app displays instructions and does not execute SQL or spreadsheets.
