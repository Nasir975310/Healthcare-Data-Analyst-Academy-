# Academy v2.5.0 — Advanced SQL and Database Engineering

## Added
- PostgreSQL 15+ setup guide for CachyOS/Ryoku, Windows and Docker.
- Dedicated PostgreSQL mastery module with ten progressive challenges.
- Normalised training schema and PostgreSQL seed script based on synthetic Academy data.
- Advanced query set covering anti-joins, CTEs, window functions, set operations and healthcare utilisation.
- Performance lab for EXPLAIN, ANALYZE, B-tree/composite/partial indexes and planner statistics.
- Views, materialized views, PL/pgSQL trigger/function and transaction/rollback examples.
- Least-privilege role, backup/restore and migration exercise.
- Python psycopg parameterised-query demo with environment-based credentials.
- Timed client assignment and 100-point rubric.
- PostgreSQL challenge completion state included in full Academy backup export/import.

## QA performed
- Source files generated and structurally inspected.
- Synthetic seed generation reconciled to 80 encounters, 150 medication orders, five departments and 28 drug/route reference combinations.
- PostgreSQL scripts statically reviewed for schema/table/column consistency and expected PostgreSQL dialect.
- JavaScript syntax, HTML parsing, JSON parsing, Python AST, SQLite seed source counts and ZIP integrity checked.
- PostgreSQL server/client binaries were not available in the build environment. PostgreSQL SQL was therefore not executed against a live PostgreSQL instance. Learner must run scripts against a local PostgreSQL 15+ instance.
- Docker was not available in the build environment; compose stack not launched.
- PowerShell/Windows installer instructions were not executed on Windows.
- Browser interaction and cross-device testing were not performed.

## Important limitations
- Educational training environment; not production database architecture.
- Synthetic dataset only. Supplied 30-day flag is not a validated readmission outcome.
- Medication orders are not proof of administration, dispensing or adherence.
- No PHI should be used in the training project.
- PostgreSQL-specific features are not portable to SQLite without rewriting.
