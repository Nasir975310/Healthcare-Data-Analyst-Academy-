# v3.5.0 — Portfolio Showcase and Career Command Centre

## Purpose
A local-first workspace that helps convert Academy exercises into defensible portfolio evidence and organise a practical job search.

## Features
- Portfolio inventory for six representative project tracks, with status, evidence notes, confidence rating, repository URL and limitations.
- Role targeting for hospital/healthcare analytics, clinical data, pharmacovigilance, RWE/HEOR and healthcare vendors.
- Application pipeline with employer, role, job URL, date, stage, self-assessed fit score and next action.
- CV bullet evidence mapper. It combines user-entered facts; it does not invent metrics or validate claims.
- Interview practice log with question/topic, score and reflection.
- Weekly execution plan with completion tracking and evidence.
- Case-study builder with Markdown export.
- Portfolio summary Markdown export and v3.5-specific JSON backup/import.

## Use
1. Start the Academy through the included local HTTP server instructions.
2. Open **Portfolio & career command centre** in the sidebar.
3. Update portfolio rows only after producing the artefact and being able to reproduce/explain it.
4. Record applications and next actions as they occur.
5. Keep interview reflections specific: identify the gap and schedule a practice task.
6. Export the v3.5 backup periodically. Use the Academy's main backup for the full platform.

## Evidence and integrity rules
- Synthetic Academy data must be disclosed as synthetic.
- Do not include patient identifiers, PHI, confidential employer information, passwords, API keys or private recruiter correspondence in portfolio exports.
- A course completion is not equivalent to a production deployment or work experience.
- Do not describe medication orders as administration, dispensing or adherence.
- Distinguish association from causation; disclose cohort definitions, missingness, exclusions, uncertainty and limitations.
- Fit scores are self-assessment aids, not a probability of being hired.

## Storage and limitations
The module stores data in browser localStorage on the current browser profile. It has no account, cloud sync or server-side storage. Clearing browser site data may erase records; export backups. The module does not submit job applications, access job boards, generate a verified CV, or validate portfolio links. The CV bullet builder uses only entered text and requires manual fact checking.

## QA boundary
Static JavaScript syntax, HTML structure, resource references and package integrity were checked for this release. The module was not subjected to automated browser interaction testing or cross-browser/mobile testing. This is a learning and organisation tool, not a recruitment or credentialing service.
