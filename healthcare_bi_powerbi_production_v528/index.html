Build sequence

  1. Import data/*.csv into Power BI Desktop or paste the corresponding Power Query templates.
  2. Apply data types and validate keys. Run python scripts/validate_sources.py.
  3. Create DimDate and paste explicit measures from dax/healthcare_kpi_measures.dax.
  4. Build the star schema described in model/semantic_model.md. Avoid fact-to-fact joins.
  5. Create executive, clinical observations, medication utilization and data-quality report pages.
  6. Configure region/facility RLS using a managed mapping table. Test both allowed and denied users.
  7. Reconcile report totals, document refresh behavior and review Performance Analyzer results.

Clinical and technical boundaries

All records are synthetic. BP values are descriptive examples; threshold flags are not diagnoses, guideline-based control rates or treatment recommendations. No patient data should be added to a public portfolio.

Power BI Desktop is Windows software. On Ryoku/Linux, use a supported Windows VM or remote Windows environment. M and DAX templates were not executed in Power BI Desktop/Service here; no PBIX, tenant deployment, live RLS test or incremental-refresh policy is included.
