# PostgreSQL mastery resources

1. Read `platform-setup.md`.
2. Create a disposable `hda_training` database.
3. Run `../sql/postgresql_mastery/schema.sql`, then `seed.sql`.
4. Complete the browser challenges and SQL scripts.
5. Finish `security-backup-lab.md` and the timed client assignment.
6. Use `requirements-postgresql.txt` and `postgres_connection_demo.py` for Python access.

The seed dataset is synthetic and derived from the Academy's existing synthetic encounter/order files. PostgreSQL-specific scripts require a PostgreSQL server and have not been executed in this build environment unless the release QA log explicitly says otherwise.
