# Tracker instructions

Open the CSV files in LibreOffice Calc, ONLYOFFICE or another spreadsheet editor.

## application_tracker.csv
Add one row per real application. Use a unique ID such as `APP-2026-001`. Keep job URLs and dates accurate. Suggested statuses: `To Review`, `Shortlisted`, `Applied`, `Recruiter Screen`, `Interview`, `Assessment`, `Offer`, `Rejected`, `Withdrawn`, `No Response`.

Do not enter passwords, identity numbers, bank information or sensitive patient information.

## weekly_scorecard.csv
Create one row per week. Count actual targeted roles reviewed, submitted applications, networking contacts, practice sessions, portfolio changes and responses. Do not count drafts as submitted applications.

## skills_evidence_matrix.csv
Update only when you have a tangible artifact or can independently demonstrate the skill. Tool installation alone is not proficiency evidence.
