# 30-Day Career Execution Plan

The plan assumes the portfolio candidate still needs human publication review and remote GitHub verification. Do not wait 30 days before applying: begin with suitable roles while improving the portfolio.

## Week 1 — Positioning and proof
- Day 1: Confirm Pharm.D status, graduation date, contact details and CV facts.
- Day 2: Create a one-page master CV and a two-page detailed version.
- Day 3: Review the synthetic portfolio repository file by file; confirm data provenance.
- Day 4: Decide license and repository visibility after review.
- Day 5: Create a dedicated GitHub repository and publish the reviewed project.
- Day 6: Check remote Actions and run a clean clone.
- Day 7: Update LinkedIn and add verified portfolio links.

## Week 2 — Applications begin
- Identify 25 relevant openings across healthcare analytics, clinical data, research data and pharmacovigilance.
- Apply to 8–10 well-matched roles; tailor the CV headline and skills section.
- Contact 5 alumni/recruiters/clinical research professionals with concise, role-specific messages.
- Practice explaining the synthetic outpatient project in five minutes.
- Practice SQL joins, grouping, NULL handling and data-quality questions.

## Week 3 — Interview and skills evidence
- Apply to another 8–10 suitable roles.
- Complete one SQL case exercise and one Excel reporting exercise.
- Build or refine one Power BI report from the synthetic dataset; do not claim a PBIX exists until built and tested.
- Prepare examples for data quality, confidentiality, metric definitions and communicating limitations.
- Follow up on applications where appropriate and within employer norms.

## Week 4 — Measure and adjust
- Apply to another 8–10 relevant roles.
- Review application-to-screen response rate by role family.
- If analytics roles produce no response, improve the evidence and broaden to clinical data/research coordinator roles.
- If pharmacovigilance roles respond better, prepare ICSR and safety-case learning evidence.
- Set the next 30-day target from actual response data.

## Weekly operating targets

- 8–10 tailored applications.
- 5 professional networking contacts.
- 3 focused technical practice sessions.
- 1 portfolio improvement backed by evidence.
- 1 weekly review of response rates and skill gaps.

Quality matters more than sending generic applications. Never pay an employer or recruiter to secure a job.
