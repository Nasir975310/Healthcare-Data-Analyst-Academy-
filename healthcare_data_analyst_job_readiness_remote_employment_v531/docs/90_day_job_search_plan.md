# 90-day job-search execution plan

Designed as a flexible plan alongside study or other commitments. Track completed outputs, not hours alone.

## Days 1–15: Evidence audit
- Complete the v5.31 readiness assessment baseline.
- Review SQL, Excel, Python and Power BI gaps.
- Select two target role families.
- Audit two portfolio projects for reproducibility, QA and privacy.
**Exit evidence:** baseline score, gap list, two role targets.

## Days 16–30: Portfolio repair
- Improve one end-to-end project.
- Add SQL queries, data dictionary, QA log and executive summary.
- Publish sanitized GitHub repository.
- Prepare a concise project walkthrough.
**Exit evidence:** one polished public project and 5-minute walkthrough.

## Days 31–45: Interview practice
- Complete timed SQL and Excel exercises.
- Explain a dashboard and data model aloud.
- Practice six behavioural questions using STAR.
- Complete one mock case study.
**Exit evidence:** timed results and recorded/self-reviewed interview notes.

## Days 46–60: Applications
- Tailor resume to each role.
- Build a tracker with company, role, date, source, status and follow-up.
- Apply only where minimum requirements are plausibly met.
- Request feedback and refine targeting.
**Exit evidence:** targeted applications and a review of response rate.

## Days 61–75: Practical work simulation
- Complete a client brief, estimate scope and produce handover.
- Practice asynchronous status updates and issue escalation.
- Improve weak assessment sections.
**Exit evidence:** completed simulated delivery and updated score.

## Days 76–90: Iterate
- Review application conversion and interview feedback.
- Strengthen the weakest portfolio evidence.
- Expand target roles only when skills support them.
- Set the next 30-day plan.
**Exit evidence:** updated portfolio, resume, tracker and readiness score.

Do not interpret a fixed application count as a guarantee of employment. Hiring outcomes depend on market conditions, eligibility, experience and employer selection.
