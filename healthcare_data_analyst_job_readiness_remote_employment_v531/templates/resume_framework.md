# Resume framework — entry-level healthcare data analyst

Keep the resume truthful, concise and tailored to the vacancy.

## Header
Full name | City, India | professional email | phone | LinkedIn | GitHub/portfolio

## Summary (3 lines)
Pharm.D graduate/candidate with healthcare-domain knowledge and practical training in [tools actually used]. Built [number] portfolio projects using [synthetic/public data]. Seeking [specific role] focused on [relevant tasks].

## Skills
- Analytics: Excel, SQL, Python/pandas, statistics
- BI: Power BI, DAX, Power Query
- Healthcare: clinical terminology, medication-use concepts, research methods
Only list skills you can demonstrate in an interview.

## Projects (use evidence-based bullets)
**Project name — Portfolio / academic project**
- Built [pipeline/model/dashboard] using [tools] on [synthetic/public dataset].
- Implemented [specific checks or methods].
- Validated [specific result] using [method].
- Documented [limitations, reproducibility and handover].

## Education
Degree, institution, location, dates; include thesis only if relevant.

## Certifications
Only completed, verifiable certifications. Separate in-progress learning from completed credentials.

## Avoid
- Claiming clinical system access you did not have.
- Calling synthetic outcomes hospital performance.
- Inflating proficiency ratings.
- Listing every technology you have merely installed.
- Publishing patient data, credentials or private repository contents.
