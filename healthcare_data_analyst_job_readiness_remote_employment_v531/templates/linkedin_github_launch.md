# LinkedIn and GitHub launch checklist

## LinkedIn
- Headline describes target role and credible skills.
- About section explains Pharm.D domain background plus analytics portfolio.
- Featured section links to 2–3 strongest projects.
- Experience distinguishes employment, academic work and self-directed projects.
- Skills match demonstrated abilities.
- No confidential data or exaggerated claims.

## GitHub
- Public repositories contain only synthetic or appropriately licensed public data.
- README states purpose, data provenance, setup, run commands, outputs and limitations.
- Requirements and versions are documented.
- No `.env`, API keys, credentials, patient data, database dumps or private client files.
- Add `.gitignore`, license where appropriate, and clear commit history.
- Include screenshots only when sanitized and accurately labelled.
