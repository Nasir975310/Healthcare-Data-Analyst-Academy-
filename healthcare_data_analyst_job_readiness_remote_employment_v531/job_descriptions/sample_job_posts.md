# Practice job postings (fictional)

## Posting A — Junior Healthcare Reporting Analyst
**Work mode:** remote-first, India. **Experience:** entry-level / 0–2 years.
- Clean monthly hospital operations files.
- Write SQL queries and reconcile counts.
- Maintain Power BI reports and metric definitions.
- Document data issues and coordinate with operations teams.
**Must demonstrate:** Excel, SQL joins/aggregations, basic Power BI, accuracy and written communication.
**Interview exercise:** reconcile two extracts with a duplicate encounter and an orphan patient key.

## Posting B — Clinical Research Data Assistant
**Work mode:** hybrid/remote subject to study needs. **Experience:** entry-level.
- Maintain study trackers and data dictionaries.
- Run edit checks and query missing/inconsistent values.
- Prepare descriptive summaries under a documented analysis plan.
**Must demonstrate:** Excel, research methods, careful documentation and confidentiality.
**Interview exercise:** identify protocol deviations and missing visit data in a synthetic study extract.

## Posting C — Pharmacy Utilization Reporting Associate
**Work mode:** remote reporting team. **Experience:** 0–2 years.
- Summarize medication orders by class and period.
- Validate code lists and denominators.
- Prepare recurring reports for pharmacist review.
**Must demonstrate:** pharmacy terminology, SQL/Excel and cautious interpretation.
**Interview exercise:** distinguish medication orders from dispensing and adherence.

## Posting D — Power BI Healthcare Analyst
**Work mode:** remote. **Experience:** 1–3 years.
- Maintain dimensional models and DAX measures.
- Improve refresh reliability and dashboard performance.
- Implement and test role-level access.
**Must demonstrate:** Power Query, DAX, SQL, star schemas and portfolio evidence.
**Interview exercise:** diagnose a many-to-many relationship and a duplicated total.
