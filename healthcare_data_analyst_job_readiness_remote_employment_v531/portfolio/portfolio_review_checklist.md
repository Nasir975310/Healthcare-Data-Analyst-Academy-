# Portfolio review checklist

Score each item 0 (absent), 1 (partial), 2 (clear and evidenced).

- [ ] Problem statement and intended audience
- [ ] Synthetic/public-data provenance and permitted use
- [ ] Data dictionary and table grain
- [ ] Reproducible ingestion and transformation steps
- [ ] Data-quality checks and exception log
- [ ] SQL queries with comments and expected output
- [ ] Statistical methods with assumptions and caveats
- [ ] Dashboard with defined KPIs and clear units
- [ ] Validation and reconciliation evidence
- [ ] README with setup and run instructions
- [ ] Screenshots or sanitized preview
- [ ] Limitations and next steps
- [ ] No patient identifiers, secrets, tokens or private data
- [ ] Git history and meaningful commit messages
- [ ] Short executive summary understandable to a non-technical reader

Maximum 30 points. Suggested portfolio gate: at least 24/30 and no privacy/security failure. A score is a self-review aid, not employer endorsement.
