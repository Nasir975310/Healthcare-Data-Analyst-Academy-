# Variable dictionary guide

Each variable should have a stable machine name, human label, role, data type, unit, operational definition, permissible values, source, collection time, missing-value codes, derivation logic and validation rules. Prefer one row per variable per version. Do not overload one field with multiple concepts. Store dates in unambiguous ISO 8601 form and retain units. Document whether categorical values are mutually exclusive and exhaustive. Keep direct identifiers out of analytical extracts unless essential and approved.
