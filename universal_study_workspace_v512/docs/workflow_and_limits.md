# Workspace workflow and limits

1. Choose a study design template.
2. Enter a question, domain and setting.
3. Define target population and eligibility.
4. Specify time origin, baseline and follow-up.
5. Add variables with role, type, unit and operational definition.
6. Review design-specific required fields and automated warnings.
7. Export a JSON study specification for version control and review.

The browser builder does not collect patient-level data, calculate sample size, select a statistical model or grant protocol approval. The Python validator checks basic structure and consistency; it cannot establish scientific validity.
