# Repository release checklist

- [ ] Repository title and description accurately describe an academic synthetic-data project.
- [ ] README contains business question, setup, run commands, outputs and limitations.
- [ ] Synthetic-data warning appears in README and dataset documentation.
- [ ] Data dictionary and metric contract are present.
- [ ] Tests pass from a clean clone.
- [ ] SQL and Python outputs reconcile to source counts.
- [ ] No patient-identifiable data, secrets, credentials, `.env`, database files or logs.
- [ ] `.gitignore` excludes generated databases, caches, virtual environments and outputs as intended.
- [ ] SHA-256 manifest is regenerated after final input change.
- [ ] All links and screenshots are accurate and current.
- [ ] Screenshots do not expose local paths, usernames, credentials or unrelated windows.
- [ ] No claim of production deployment, client use or clinical impact.
- [ ] License is included only when licensing rights are clear.
