# Healthcare Data Analyst Academy — product showcase

**v5.60.3 maintenance release.** This is an offline-first educational repository and portfolio toolkit, not a single production SaaS platform.

## What is included
- Learning materials for Excel, SQL, Python, statistics, research methods, data quality, ETL, databases, healthcare data engineering, BI and reporting.
- Practice modules, exercises, capstones, scripts, datasets, data dictionaries, metric contracts and tests.
- Synthetic outpatient and medication-utilisation analytics projects with explicit non-clinical-use safeguards.
- Portfolio reproducibility, QA, publication-readiness and evidence-capture tools.
- Career materials: CV/LinkedIn templates, role-fit evaluation, interview preparation, application tracking, vacancy verification and vacancy evidence capture.

## Suggested flagship route
1. Excel/SQL foundations.
2. Python and pandas analysis.
3. Healthcare data quality and statistics.
4. Synthetic outpatient analytics capstone.
5. Reproducible report and portfolio case study.
6. Career launch and evidence-based applications.

## Start using it
1. Extract the archive.
2. Read `README.md`, `ACADEMY_CATALOG.md` and `STABILIZATION_GUIDE.md`.
3. Open `index.html` in a modern browser.
4. Start with one learning phase and one flagship project rather than attempting every module at once.
