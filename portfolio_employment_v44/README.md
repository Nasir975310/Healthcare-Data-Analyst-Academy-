# v4.4 Portfolio-to-Employment Pipeline

Use the module to map role requirements to evidence, convert completed projects into repository README/case-study drafts, write factual CV bullets, track applications and rehearse STAR interview stories.

It does not publish to GitHub, submit applications, inspect local evidence or verify claims. Review all generated text. Never place PHI, secrets, confidential employer data or unauthorized datasets in public repositories.

The application tracker, role-skill map, project records and STAR stories are stored in browser localStorage. Export JSON backups regularly. Generated README/case-study/CV text is a draft and must be checked against the actual work. This release does not connect to GitHub, job boards or email.
