Data-quality indicators

Metric definitions

  • Paired record: baseline and follow-up SBP both within 70–250 mmHg and primary class present.
  • SBP change = baseline SBP − follow-up SBP.
  • Comorbidity filter uses available indicator columns; blank values are not assumed to mean absence.
  • Duplicate IDs are counted in raw filtered rows but unique IDs are reported separately.
