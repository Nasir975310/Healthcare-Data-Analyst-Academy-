# Repository release gate

- [ ] README explains problem, scope, grain, setup, run, outputs and limitations.
- [ ] Data dictionary and provenance are present.
- [ ] Synthetic/authorised data status is explicit.
- [ ] No PHI, secrets, tokens, credentials or confidential exports.
- [ ] .gitignore excludes local environments and sensitive artefacts.
- [ ] Code executes from a clean environment.
- [ ] Tests cover schema, keys, joins and key calculations.
- [ ] Outputs regenerate deterministically or variability is documented.
- [ ] Figures/tables have units, labels, denominators and dates.
- [ ] SQL dialect and version are declared.
- [ ] Known defects and limitations are documented.
- [ ] Git diff reviewed; commit history meaningful.
- [ ] Peer review or self-review record included.
- [ ] Public repository visibility approved.
