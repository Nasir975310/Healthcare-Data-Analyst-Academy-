# Portfolio Engineering and Technical Interview Readiness

This module teaches how to turn analytical work into inspectable, reproducible professional evidence. It does not claim that a GitHub profile or certificate guarantees employment.

## Recommended sequence
PE-01 → PE-02 → PE-03 → PE-04 → PE-05 → PE-06 → PE-07 → PE-08.

Each module contains outcomes, tasks and acceptance criteria in `modules.json`. Complete each task in a real local repository, not only in the Academy browser.

## Suggested role-specific project mix
- Healthcare / hospital analyst: hospital operations KPI review + SQL prescribing analysis + dashboard.
- Clinical data / research: clinical trial QC + study cohort analysis + reproducible statistical report.
- Pharmacovigilance: synthetic case quality review + seriousness/chronology analysis + signal-screening limitations.
- RWE / HEOR: cohort specification + claims-based proxy analysis + confounding/robustness plan.
- Healthcare vendor analyst: remote client delivery simulation + data quality ETL + dashboard handoff.

## Repository rule
Only publish synthetic or explicitly authorised data. De-identification is not automatic permission to publish. Do not commit PHI, patient identifiers, access tokens, credentials, client exports, database dumps or screenshots of clinical systems.

## Tools
Git and GitHub CLI are available in the user's intended CachyOS/Ryoku setup. Commands below are platform-neutral where possible. PowerShell notes are included for Windows users. This Academy does not push to GitHub or create repositories on the user's behalf.
