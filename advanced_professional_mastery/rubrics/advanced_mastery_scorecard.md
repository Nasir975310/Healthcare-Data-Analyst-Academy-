# Advanced Mastery Scorecard

| Domain | Points | Evidence expected |
|---|---:|---|
| SQL investigation | 25 | Correct grain, CTE/window/anti-join logic, safe joins, explain plan |
| Statistical validation | 25 | Cohort flow, crude/adjusted models, robust CI, confounding discussion |
| Dashboard review | 20 | Reconciled values, metric contract, relationship/cardinality diagnosis |
| Reproducibility and QA | 15 | Environment, clean run, automated checks, output manifest |
| Executive communication | 15 | Concise decision-focused report, uncertainty and limitations |

**Critical fail:** PHI/credentials, fabricated values, concealed exclusions, unauthorised data, unsupported causal/clinical claims. Critical failures block a pass.
